# Stack-Based Expression Evaluator

**Module:** DCOMP320 – Data Structures and Algorithm
**Assignment:** Stacks Implementation (Individual Assignment, 10%)
**Student:** Abdullah Gabriel Sanu
**Language:** Python 3.8 or later (no external libraries needed)

## Description
This program reads mathematical expressions from a text file (`input.txt`),
evaluates each one using a custom `Stack` class, and writes the results to
`output.txt`. The output keeps the same layout as the input: each result
replaces its expression, and the separator lines (`-----`) are kept.

## How to Run
1. Install Python 3.8+ and check it with `python --version`.
2. Put `stack_evaluator.py` and `input.txt` in the same folder.
3. Open a terminal in that folder.
4. Run: `python stack_evaluator.py`
5. Open `output.txt` to see the results.

To use other file names:
`python stack_evaluator.py my_input.txt my_output.txt`

## Input File Format
- One mathematical expression per line.
- Expressions are separated by a line containing only dashes (3 or more), e.g. `-----`.
- Supported: numbers (whole or decimal), `+`, `-`, `*`, `/`, parentheses `( )`, unary minus (e.g. `-5`, `2 * -3`), and spaces.

Example `input.txt`:
```
3 + 5 * 2
-----
(8 / 4) + 7 * 2
-----
10 - (2 + 3) * 4
```

## Output File Format
Each expression is replaced by its result; separator lines stay the same.

Example `output.txt`:
```
13
-----
16
-----
-10
```
- Whole-number results are shown without decimals (`13`, not `13.0`).
- Other results show up to 4 decimal places (`7 / 2` gives `3.5`).
- An invalid expression produces a message on its own line, e.g. `Error: Division by zero`, `Error: Mismatched parentheses`, `Error: Invalid expression`. The program then continues with the next expression.

## How It Works
1. `tokenize()` splits the line into numbers, operators and parentheses.
2. `evaluate_expression()` uses two stacks, one for operands and one for operators. Operator precedence (`*` and `/` before `+` and `-`) and parentheses are handled with the operator stack.
3. `process_file()` reads the input line by line, evaluates each expression and writes the result.

## Assumptions and Limitations
- Each expression is on a single line.
- Only `+`, `-`, `*`, `/` are supported (no powers, modulus or functions).
- Operators of equal precedence are evaluated left to right.
- Calculations use floating-point numbers, so very large or very precise results may be rounded.
- Implicit multiplication such as `2(3+4)` is not supported and gives an error.
- The sample output in the assignment brief shows 17 for `(8 / 4) + 7 * 2`; the correct answer is 16, which this program outputs.
